## Usage

1. Join **Violence Districk or others** on Roblox.
2. Get the latest script from our Discord and run it in your executor.
3. Enter your key and press **Check Key**.
4. The menu will open.

---

## Get a Key

1. Join our Discord: https://discord.gg/solanahub
2. Get your key from the key channel.
3. Press **Paste** in the key system, then **Check Key**.

---

## Troubleshooting

**Key is invalid:** Make sure there are no extra spaces and that the key has not expired.

**Menu does not appear:** Make sure you are inside the game, then execute the script again.

**Error on execute:** Update your executor. If it still fails, send a screenshot in our Discord.
